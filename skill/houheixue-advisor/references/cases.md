# 人物案例速查與原文要句

出處皆為李宗吾《厚黑學》，完整原文見 [original-text.md](original-text.md)。

## 人物案例速查

| 人物 | 厚黑類型 | 事蹟與職場啟示 |
| --- | --- | --- |
| 曹操 | 黑之代表 | 殺呂伯奢、孔融、楊修，自稱寧可我負人；卻讓中原名流傾心歸服，是「心子漆黑，招牌透亮」的第二境界。啟示：手段再狠，招牌要亮。 |
| 劉備 | 厚之代表 | 先後依附曹操、呂布、劉表、孫權、袁紹，寄人籬下不以為恥；善哭，遇到難事痛哭一場便轉敗為功。啟示：放低身段、示弱，往往比硬碰硬有效。 |
| 孫權 | 厚黑兼備但不到底 | 奪荊州殺關羽後又向蜀請和；向曹稱臣後又與魏絕交。啟示：兩邊都沾，就兩邊都不夠徹底。 |
| 司馬懿 | 集大成者 | 欺人孤兒寡婦（黑），受巾幗之辱而不動（厚）。諸葛亮這樣的王佐之才也拿他沒辦法。啟示：受辱不動，才能等到對手先耗盡。 |
| 諸葛亮 | 才高但非厚黑名家 | 鞠躬盡瘁，終不能取得中原尺寸之地。啟示：能力與忠誠不等於能贏。 |
| 劉邦 | 天資最高 | 項羽要單挑，他笑著推辭說寧鬥智不鬥力；被酈生責備怠慢長者，立刻起身道歉；事成後殺韓信、彭越。啟示：該低頭時立刻低頭，該下手時毫不猶豫。 |
| 張良 | 厚學之師 | 圮上老人教他的就是臉皮厚；韓信求封齊王時在旁點醒劉邦。啟示：身邊要有能在關鍵時刻提醒你忍一下的人。 |
| 項羽 | 厚黑皆缺 | 婦人之仁（鴻門宴不忍下手）、匹夫之勇（垓下不肯渡江，自覺無面目見江東父老）。啟示：心軟加上愛面子，是最常見的失敗組合。 |
| 韓信 | 厚而不黑 | 能受胯下之辱；但感念劉邦解衣推食之恩，不聽蒯通自立，終遭誅滅。啟示：別把老闆的小恩小惠當成長期保障。 |
| 范增 | 黑而不厚 | 中了陳平反間計，憤然求去，途中疽發背死，「因小不忍，壞了大事」。啟示：被冤枉時甩門走人，等於把位置拱手讓人。 |
| 唐太宗 | 黑的擴充 | 李宗吾以小孩搶糕餅、推打哥哥比喻人性本有的厚黑，唐太宗把它擴充到極致，終成霸業。 |
| 王莽 | 露底之敗 | 敗在厚黑露了底。啟示：最忌讓人看穿你的算計。 |
| 管仲 | 二法並用的天下才 | 狄人伐衛時按兵不動，等衛亡了才出來興滅繼絕（補鍋）；召陵之役不責楚國僭稱王號，只責它不貢包茅（鋸箭）。以補鍋始，以鋸箭終。 |
| 鄭莊公 | 補鍋法 | 縱容共叔段多行不義，再舉兵征討。啟示：先讓對方的問題充分暴露，再出手才名正言順。 |
| 明末武臣 | 補鍋失敗 | 故意放走被圍的流寇，後來制不住，國破君亡。啟示：鍋敲爛了要補得起，否則就是自己背鍋。 |
| 岳飛、于謙 | 取箭頭之禍 | 一個想迎回二帝，一個真把明英宗接了回來，都遭殺身之禍。啟示：替上面解決他其實不想解決的問題，危險。 |
| 王導 | 鋸箭留箭頭 | 叛賊不討，回信說要等陶侃，等於留著箭頭等內科；新亭對泣時義形於色，其實說兩句漂亮話就了事，史稱「江左夷吾」。 |

## 原文要句（可於回答中引用）

- 「我們雖不想實行厚黑，也須提防人在我們名下施行厚黑，所以他們的法術，我們不能不知道。」
- 「讀者如果不明了這個道理，認真厚黑起來，是要終歸失敗的。」
- 「喜怒哀樂皆不發謂之厚，發而無顧忌，謂之黑。」
- 「不曰厚乎，越磨越厚；不曰黑乎，越洗越黑。」
- 「有失敗之事於此，君子必自反也，我必不厚；其自反而厚矣，而失敗猶是也，君子必自反也，我必不黑。」
- 「大凡做大事的人，那有動輒生氣的道理？」
- 「恐字與捧字，是互相為用的，善恐者捧之中有恐……善捧者恐之中有捧。」
- 「非到無可奈何的時候，恐字不能輕用。」
- 「恭字對飯甑子所在地而言，不必一定是上司；繃字對非飯甑子所在地而言，不必一定是下屬和老百姓。」
- 「吾道原是活潑潑地，運用之妙，存乎一心。」
- 「笑罵由他笑罵，好官我自為之。」
- 「厚黑的施用，定要糊一層仁義道德，不能把它赤裸裸的表現出來。」
- 「面子上應當糊以甚麼東西，是在學者因時因地，神而明之，而裏子的厚黑二字，則萬變不離其宗。」
- 韓非子：「陰用其言而顯棄其身。」
